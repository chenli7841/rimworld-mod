# Lesson 23 — 古代档案回收任务验收

## 当前实现

- 任务：`LiAIChat_AncientArchiveRecovery`。
- 原版按 tag 组合档案遗址与 SleepingMechanoids；档案 GenStep 登记生成的文献引用。
- QuestPart 每 250 ticks 检查目标文献；至少一本的 MapHeld 为玩家基地时成功。
- 文献引用使用 Scribe 保存；遗址消失不会直接结束回收。
- 全部已登记文献损毁或引用丢失时失败；文献未生成且遗址已消失时也失败。
- 自然抽选权重 0.5、最低点数 400、允许暴力任务、位置距离 4～12 格。
- 同一任务标签仅允许一份进行中任务；15 天间隔从上次出现计时。
- 抵达期限 20 天，地图生成后关闭此期限；Lesson 23.18 新增首次地图生成后 30 天回收期限，使用原版非重复激活的 QuestNode_Delay。
- 动态进度支持中英文，任务及遗址定义有简体中文翻译。

## 游戏内回归清单

使用测试存档，重启加载新 DLL/Defs；强制生成可能绕过自然抽选条件。

| 场景 | 预期 |
|---|---|
| 500 点生成并进入 | 档案建筑、目标文献、休眠机械族正常生成 |
| 殖民地已有其他文献 | 不会立即完成新任务 |
| 带走一本，离开遗址 | 回家前任务继续等待 |
| 文献在人或动物背包中回家 | 至多 250 个游戏 ticks 后成功 |
| 远行途中保存、读档、回家 | 文献引用保留，能完成 |
| 文献全部损毁 | 任务失败 |
| 20 天未进入 | 任务过期失败 |
| 已进入后超过 20 天 | 抵达超时已关闭，回收继续 |
| 首次地图生成后满 30 天，未回收 | 回收超时失败 |
| 回收倒计时中保存、读档或重返遗址 | 倒计时保留，不重新给 30 天 |
| 新任务进行中再次尝试正常生成 | 同标签任务被拦截 |
| 上次出现不足 15 天且已结束 | 自然抽选不再选中它 |
| 超过 15 天且上一份已结束 | 恢复资格，但不保证立刻出现 |
| 关闭暴力任务 | 正常生成检查拒绝 |
| 简体中文生成新任务 | 名称、正文、进度和遗址介绍正常，无裸翻译键 |

## 已知边界，不能当作已解决

1. Lesson 23.17 已收紧成功条件：基地内落地的文献，或持有链中的 Pawn 均存活且属于玩家、并至少有一个 Pawn 持有者的文献。非 Pawn 容器暂不算回收，取出落地即可。需游戏内验收。
2. Lesson 23.17 使用 PreTraded 记录售出状态并存档，售出文献不再算可回收目标；任务尚未结束时买回可恢复资格，已结束任务不会重开。旧存档无法追溯更新前的交易。Lesson 23.18 为新生成任务增加回收期限，旧任务不会自动获得该 QuestPart。
3. 遗址地图生成成功但没有登记任何文献时，任务可能一直等待到遗址消失。
4. 旧任务不会自动获得后来新增的 QuestPart 或唯一标签；旧任务名称和正文也可能已存入存档。
5. 原版自然抽选有其他权重修正，0.5 不能解释为固定概率；需要实际游玩数据才能平衡频率。

## 下一阶段建议

验收 Lesson 23.17：玩家背包到家成功，非玩家背包到家不成功，售出全部目标后失败，售出状态在读档后保留。再评估抵达后的回收期限。不要仅凭 MapHeld 为 null 判定丢失，因为正常远行中的文献也没有地图。
