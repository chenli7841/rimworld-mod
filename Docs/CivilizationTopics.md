# 文明专题：实现与扩展方案

当前启用 19 个专题：首批四本、现有馆藏中的《忏悔录》《理想国》《尼各马可伦理学》《物种起源》《新工具》《九十五条论纲》，以及本轮补入馆藏池的《君主论》《社会契约论》《国富论》《时间简史》《共产党宣言》《孙子兵法》《论战争》《法的精神》《计算机器与智能》。

## 研究循环

1. 馆藏沿用 `ColonyLibrary`：至少一个玩家基地地图上存在对应的、已识别的古代文献。落在基地地图上的文献和放入原版书柜的文献都会计入；无需完整复原章节，也不消耗文献。旅行队背包、访客携带物和未识别文献不计入。
2. 选择专题与实际增加研究点均检查馆藏。研究途中失去最后一本符合条件的文献会暂停进度，归还后可继续；普通研究与额外研究点两条路径均检查。
3. 完成时从该专题的实际奖励池不重复抽取三项。持续效果作用于玩家控制的殖民者，固定持续 7 个游戏日（420,000 ticks）；即时效果在完成瞬间结算。不同专题的奖励可以并存；同一专题在效果或冷却期间不能再次完成或重复领奖。
4. 到期清除该专题自己的研究进度，其他研究不变；随后冷却 2–4 个完整游戏日。冷却时间在领奖时抽取并保存，读档不会重抽。书在奖励期间丢失不会提前移除已获得的奖励，但下一轮仍要求馆藏。
5. 最近连续完成同一本书，会使下一轮效率依次为 80%、64%、51.2%、40%，最低 40%。**完成**另一专题后解除前一本的连研折扣；仅切换选择不重置，普通科技研究也不重置。
6. 每个奖励的抽取权重为 `1 / (1 + 该奖励历史出现次数)`。初始等权，旧奖励不会被排除，已抽完所有奖励仍可继续。历史按专题独立保存。

奖励和到期时间、冷却时间、轮换记录、参与者、历史抽奖、最近一次结论都写入游戏存档。旧版已经完成、但没有专题奖励记录的项目会在载入时重新开放，不补发奖励。研究面板显示馆藏状态、奖励池、当前效果/冷却剩余时间、研究效率和上次结论。能力面板中的普通属性加成也附有解释。

语义边界：

- RimWorld 的精神崩溃阈值越低越稳定，因此实现为降低 5 个百分点。
- 心情变化效果调整心情向当前目标移动的速度，不凭空添加恢复量，不突破当前目标心情。受伤恢复效果适用于存在非永久伤势的时期，不单独鉴别伤势是否来自战斗。
- 疼痛效果只减轻 `Pain` 思绪的负面心情，不降低生理疼痛，也不削弱受虐狂的正面疼痛思绪。
- 关系效果减轻现有负面社交记忆的好感影响，不修改派系关系或永久关系值。到期恢复原来的记忆影响。
- 活动效果增加正面心情记忆收益，不提升仪式质量分数，也不增加仪式物品或招募奖励。未安装 Ideology 仍可作用于原版聚会等活动。
- 阅读理解效果提高本模组古代文献的持续阅读进度，不直接解锁收费复原章节，不让一次阅读自动掌握全书。
- 普通属性/思绪仍遵循原版缓存刷新周期，界面数值可能在下一次原版刷新时更新。

**暂未纳入奖励池**：访客招待效果、制作失败率、科研事故或错误事件概率、敌袭预警、伏击收益、派系关系恶化、重大决策额外选项、机械体维护，以及通讯/扫描/远行事件收益。原版没有统一的这些接口，后续需要明确具体机制或兼容模组，不能以相近属性冒充这些效果。

## 研究结论与素材

使用本地模板，不请求 ChatGPT。完成通知包括实际参与研究者、该书最近两节已经解锁的复原章节标题、该书主题结论及随机效果。无已解锁章节时明确说明是基于已识别馆藏的初步研讨，不引用未解锁正文。

最近一次结论长期保存在每个专题的状态中，也记录到殖民地事件日志。对话提示词会提供这些共同研讨素材，并标注效果是否已过期；这不等于每名殖民者个人掌握了书籍内容。新建该书评注时保存一份“专题研究素材”，后续作者回应也可以参考对应书籍最新结论。不同书籍的评注不自动混用结论。

## 验证

自动检查：运行 `Tests/Verify-CivilizationTopics.ps1`。覆盖轮换公式、奖励权重、模组 Def XML 解析、四专题/十三奖励配置、文献和属性引用，以及本机游戏程序集中的 Harmony 目标。

仍需在游戏内完成以下集成验收（命令行检查不等于已执行这些场景）：

1. 没有馆藏/只有未识别文献时不可开题；识别后可开题；普通科技不受影响。
2. 研究中移走最后一本馆藏，普通工作和额外研究点均不推进；归还后保留原进度继续。
3. 自然研究完成只给一次奖励。分别验证属性、心情变化、斗殴、疼痛、负面社交记忆、活动记忆和阅读增长；非殖民者不受益。
4. 奖励中、冷却中、研究一半时保存退出并载入；时间、奖励、进度、连研记录不重抽或丢失。
5. 7 天到期只清零对应专题；冷却到期允许再次研究；其他专题可并存，不重置普通科技。
6. 连研效率递减至下限；仅切换选择无法解除；完成其他专题后解除；重复抽取仍可能但权重下降。
7. 有/无已解锁章节时的结论均准确，通知、研究面板、对话素材与新评注素材能显示；过期结论不再被描述成当前加成。

实现接口核对已确认：`ResearchPerformed` 直接修改研究进度，不经过 `AddProgress`；调用 `FinishProject` 时进度已达到完成值。因此两条进度路径分别拦截，奖励不能依赖 `FinishProject` 前的 `!IsFinished` 判断。
